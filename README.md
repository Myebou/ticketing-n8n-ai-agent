# Ticketing Cultural — n8n AI Agent

Repositorio académico para el desarrollo progresivo de workflows en n8n aplicados a soporte de ticketing cultural.

## Autor

Alexis Paredes

## Contexto del proyecto

El proyecto toma como caso de uso un sistema de atención para consultas frecuentes de ticketing cultural: entradas no recibidas, problemas con QR, devoluciones, cancelaciones, suspensiones, cambios de fecha y derivación a revisión humana.

El flujo evoluciona módulo a módulo dentro del programa de estudios de n8n e inteligencia artificial aplicada.
